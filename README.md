# Zapret-Ultimate

**Максимальный пакет списков для обхода DPI-блокировок.**

Это форк проекта [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) с расширенными списками доменов и IP-адресов.

## Что улучшено

- Расширенные списки доменов (включая CDN и API для всех популярных сервисов)
- IP-адреса и подсети (Core Networks) для TikTok, Claude, Telegram и других
- Раздельные файлы для каждого сервиса
- Общий список `list-general.txt` для быстрого старта

## Как установить
1. Скачавай этот репозиторий
2. Распаковывай любым нормальным архиватором
3. Запускаешь файл service.bat
4. Дальше жми кнопку 1 а потом Enter
5. Выбирай свою стратегию
